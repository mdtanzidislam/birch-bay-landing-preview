# Birch Bay Resort – Landing page preview

Static preview of the new for-sale landing page for Birch Bay Resort (Wabana Lake, Grand Rapids, MN).

- `index.html` – the landing page (all sections, album gallery with popup viewer, inquiry form)
- `thank-you.html` – shown after the inquiry form is sent (use this URL as the Google Ads conversion page)
- `privacy-policy.html` – privacy policy, linked from the form and the footer
- `images/` – 50 photos from the current sale site

All pages are set to `noindex` so search engines will not list the preview.
In this preview the form checks the fields and opens the thank-you page, but it does not send the details anywhere.
